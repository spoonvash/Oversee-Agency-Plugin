== Description ==

Oversee Helpdesk is a powerful, white-label ready support ticket system for WordPress. Perfect for agencies and businesses who need a professional helpdesk solution.

**Features:**

* 📋 Full ticket management system
* 📚 Knowledge base with categories and search
* 👥 Agent assignment and team management
* 📧 Email notifications
* 🎨 White-label branding options
* 🔐 License-based activation
* 📱 Responsive design
* 🔌 REST API for integrations
* 📊 Dashboard with analytics

== Installation ==

1. Upload the plugin files to `/wp-content/plugins/oversee-helpdesk`
2. Activate the plugin through the 'Plugins' screen in WordPress
3. Go to Helpdesk → Settings → License to activate your license
4. Configure branding options as needed
