Email Actions UI for Workflows

Create eye-catching emails faster and more consistently! The Email Action UI for workflows unifies the experience you already know from Campaigns and the Email Builder, adds powerful tracking options, and slashes the learning curve for every user.

Overview of Email Actions for Workflows


The Email Action (New UI) is a redesigned experience for creating and managing emails sent from Automations → Workflows. It aligns the workflow email composer with Email Builder and Campaigns so you get the same starting options, editing tools, advanced settings, and statistics everywhere.


A unified experience shortens onboarding time and reduces mistakes. You can now choose your preferred editing path, enable advanced tracking, and view link‑level performance for workflow‑sent emails.


Key Benefits of the Email Action (Universal UI)


  • Consistent Experience: Start and edit emails the same way across Campaigns, Email Builder, and Workflows.

  • Flexible Creation: Pick Quick Compose, Smart Builder (Design/Code/Plain Text), or Select Template based on the job.

  • Deeper Tracking: Enable Link Tracking and review Click Performance with link‑level metrics and CTR.

  • Attribution Ready: Toggle UTM Parameters to pass campaign data into downstream analytics.

  • Auto‑Segmentation: Use Add Tags to automatically tag contacts based on engagement (e.g., open or click).

  • Action‑Level Stats: View Delivered, Opened, Clicked, Replied, Bounced and drill into details from the action itself.


How to Use Email Actions for Workflows


Step 1: Navigate to Workflow Campaigns


There are 2 ways to navigate to Workflow Campaigns:

  • Go to Marketing → Emails  → Campaigns → Workflow campaigns

  • Go to Automation  →  Workflows



Step 2: Add Email Actions

  • Open an existing Workflow or create a new one

  • Add or edit an Email Action.

 



Step 3: Choose how to Start


Choose the path that matches your use case—fast transactional notes, brand‑styled designs, or reusing proven templates.


  • Quick Compose (default): Simple editor for fast messages.

  • Smart Builder: Select Design, Code, or Plain Text editor to build from zero.

  • Select Template: Pick from My Templates or Templates Library.



Step 4: Preview Template (Optional)


If using a template, click the template preview’s menu to Edit Design or Remove. Decide whether to Sync Edits to Template.




Step 5: Advanced Settings


Expand Advanced Settings to enable:


  • Link Tracking → See clicks and CTR for each link.

  • UTM Parameters → Add campaign tracking tags.

  • Tags on Actions → Automatically tag contacts based on opens/clicks.


Step 6: Save and View Statistics


  • Click Save Action. Publish the workflow when ready.

  • After sending, reopen the Email action to view Statistics. Click View Details or Click Performance for deeper insights.



Frequently Asked Questions


Q: Does the new UI change how existing emails send?

No. Emails built before the update keep their original content and statistics. Open the action to upgrade its editor.


Q: Can I still edit HTML directly?

Yes, choose Smart Builder → Code Editor to paste or tweak raw HTML.


Q: Is link tracking available for workflow emails?
Yes. Enable Track Clicks in Advanced settings to measure clicks and see link‑level performance.
